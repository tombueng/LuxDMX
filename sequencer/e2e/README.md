# Sequencer end-to-end tests

Playwright drives the real app in Chromium against a **fake LuxDMX** (`test/fake-luxdmx.mjs`): it
serves the real `/bridge` and `/remote` pages from the firmware, passes `/ws` relay messages on
like the box does, and records every DMX frame it receives, with a
timestamp, so the tests assert what a box would get (fade times and effect periods are measured
from the frame history, not read from the UI). `hw.spec.ts` runs the same paths against a real box.

```sh
npx playwright test                                   # everything against the fake box
LUXDMX_HOST=192.168.1.50 npx playwright test e2e/hw.spec.ts
LUXDMX_HOST=… LUXDMX_UNI=1 npx playwright test e2e/hw.spec.ts   # when universe 0 is busy
```

Every test fails on an uncaught page error or a Svelte warning (`helpers.ts`), even when its own
assertions pass. The welcome dialog comes up on every fresh start: `fresh()` closes it
(`fresh(page, true)` keeps it), `welcome()` opens it again, `demo()` starts the big demo from it on
the demo beat (a real song would come down from the internet). Touch tests use real touch events (CDP), the MIDI tests a fake Web MIDI input, the
music tests a 120 BPM kick drum file as Chrome's fake microphone (`scripts/make-test-audio.mjs`).
